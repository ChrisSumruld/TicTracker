# TicTracker
I noticed that my professor said many of the same phrases over and over again, so I thought it'd be a good opportunity to implement Blazor and make a game of tracking those phrases to help me expand my understanding of the framework.

The plan is to catalogue each quote, the time it's said, and the frequency at which it's said. There are anywhere between 70-150 entries per lecture, which, with that amount of data, allows for the building of heatmaps and in-depth predictions. After cataloguing each entry and it's frequency, I'd like to build a prediction market around it using site tokens where users can bet on the amount of times something will be said that day, when one might be said, or how many times something might be said within a certain timespan.

The goal is to learn to implement HTTPS and encryption techniques to protect all user data while keeping the site responsive and modular to allow for easy later updates.
